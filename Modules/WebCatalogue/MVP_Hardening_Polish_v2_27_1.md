# WebCatalogue v2.27.1 MVP Polish

This package focuses on closing UX/design loose ends before deeper recognition optimizations.

## Included

- Store BO live preview for public front configuration.
- Theme preset buttons: Minimal Clean, Premium Dark, Luxury Gold, Technical B2B.
- Better admin polish: hover states, empty state classes, help notes and preview cards.
- Front fallback handling for broken images.
- Safer visual preview links for store and scan pages.

## Goal

Stabilize the MVP experience and make store configuration easier to validate before saving.
